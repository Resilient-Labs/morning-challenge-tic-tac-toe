# A two player tic tac toe game buile with HTML, CSS, and JavaScript

## About the Project    

This project is a browser based game where two players can submit their names, and take turns placing their assigned symbol on the board, until one player has their symbol placed across 3 aligned squares.

## What I practiced

-Object Oriented programming
-Classes
-DOM manipulaiton
-Arrays and nested arrays
