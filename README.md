# 📊 Morning Challenge: Tic-Tac-Toe

Classic two player Tic-Tac-Toe game. 

The users can click to place their X or O and if they win, the program alerts their win in the DOM. Then after clicking 'clear' the board clears, and another game can begin. 

This game was made with CSS, HTML, and Javascript. The JS code was bit tricky here because you had to remember that the index begins count at 0, not 1.
