# Xoxo, Gossip Girl's Tic-Tac-Toe Game 👑📱💬✨

## Overview

This is a simple, interactive two-player Tic-Tac-Toe game built using HTML, CSS, and JavaScript with an object-oriented programming approach. Players alternate turns, placing their respective "X" or "O" marks on a 3x3 grid. The game dynamically updates the board, checks for winners or draws, and displays the game result on the page. It also features a reset button to start a new game.

This project showcases fundamental game logic, event handling, DOM manipulation, and clean class-based JavaScript design. It’s a great starting point for learning about game development and user interaction on the web.

## What I Learned

* **Object-Oriented Programming:** Using classes to model players, the game board, and game logic for modular and reusable code.
* **DOM Manipulation:** Dynamically updating the board and messages based on player interactions.
* **Event Handling:** Listening for clicks on the grid and reset button to control game flow.
* **Game Logic:** Implementing win condition checks and turn management.
* **User Interface:** Providing clear visual feedback with player symbols and a winner announcement.
* **Reset Functionality:** Allowing users to restart the game without refreshing the page.

## Features

* **Two-player gameplay:** Players alternate turns, placing X and O marks.
* **Clickable 3x3 grid:** Each square can be clicked to place a mark if empty.
* **Win detection:** The game checks all possible winning combinations and displays a winner message.
* **Reset button:** Clears the board and resets the game to player 1’s turn.


## How to Play

1. Open the game link in the description.
2. Players take turns clicking empty squares on the 3x3 grid.
3. Player 1 uses "X" and Player 2 uses "O".
4. When a player gets three of their symbols in a row (horizontal, vertical, or diagonal), the game announces the winner.
5. Use the "Reset" button to clear the board and start a new game.


## Technologies Used

* **HTML:** Structure and layout of the game board.
* **CSS:** Styling for the game UI and player marks.
* **JavaScript:** Game logic, event handling, and DOM manipulation.


## Code Structure

* **Players Class:** Represents a player with an assigned number and symbol ("X" or "O").
* **Board Class:** Maps to the 3x3 grid squares in the DOM.
* **Game Class:** Controls the flow of the game, manages player turns, handles clicks, checks for wins, and resets the board.
