# 📊 Morning Challenge: Tic-Tac-Toe

### Goal: Create a two player Tic-Tac-Toe game. The users should be able to click to place their X or O and if they win the program should mention their win in the DOM. Please make the game as OOP as possible.

Features:
Get 3 symbols in a row and win the game!
Pick a section, then player 2 picks a section. Go back and forth until someone wins or you tie!

Tech Used:
HTML
Javascript
CSS

Lessons Learned
Functions for winning and ties
Event listeners for every square and test cases for if something is already in that space
Resetting entire board when starting a new game
