# Tic-Tac-Woah!

A simple two-player Tic-Tac-Toe game built with HTML, CSS, and JavaScript.

## Features

- Two-player gameplay with X and O
- Alternating player turns
- Prevention of moves in occupied spaces
- Win detection for rows, columns, and diagonals
- Draw detection
- In-page game status updates
- Reset functionality
- Game logic organized with a JavaScript `Game` class

## How to Play

Player X begins the game. Players alternate selecting empty squares until one player gets three marks in a row or the board ends in a draw.

Select **Reset Game** to start over.

## Built With

- HTML
- CSS
- JavaScript
