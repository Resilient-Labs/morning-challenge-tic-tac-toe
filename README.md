## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/TicTacToeGame.git
````

2. Navigate to the project directory:

```bash
cd TicTacToeGame
```

3. Open Project File

4. Use in browser
   
## Usage

1. Click spaces in board to place X or O.
2. Alternate turns.
